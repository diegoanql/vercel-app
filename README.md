# Vercel App

Este proyecto es una landing page estática para una sección **Nosotros** con estilo premium, diseño tipo mobile app y mapa interactivo usando Leaflet.

## Vista local

Puedes abrir el archivo `index.html` directamente en el navegador o servir la carpeta con:

```bash
python3 -m http.server 3000
```

Luego visita:

```text
http://localhost:3000
```

## Despliegue en Vercel

1. Sube este repositorio a GitHub.
2. Conéctalo con Vercel.
3. Usa la configuración por defecto de despliegue para sitios estáticos.

No requiere build step ni dependencias adicionales.
